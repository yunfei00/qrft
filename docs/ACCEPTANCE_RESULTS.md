## 性能与稳定性（互不替代）

| 范围 | 实际结果 | 限制 |
|---|---|---|
| 实际 Acceptance EXE 的 1 GiB 文件 SHA256 | 1,073,741,824 字节，1.378 秒，进程采样 RSS 峰值 48,160,768 字节（约 46 MiB） | 新生成文件立即读取，受 Windows 缓存影响；随机 1 MiB 块重复写入，不是完整二维码传输或磁盘硬件带宽 |
| 真实 ZXing 核心读取合成 AVI | 210 个合法二维码，2.747 秒，76.44 帧/秒 | 小规模合成视频，真实 CLI 导出 PNG；不包含录屏设备、SMB 网络或大视频定位成本 |
| 实际 Encoder GUI 连续播放 | Windows 原生平台，600.142 秒，3195 帧，798 轮，无错误 | 验收 Runner 与 GUI 合计采样峰值 120,336,384 字节（约 115 MiB）；仅显示窗口，不含录屏链路；30/60 分钟未执行 |

GUI 600 秒报告的验收器为 Python Runner，受测对象为实际打包 GUI EXE；1 GiB 表中测量主体为实际打包 Acceptance EXE。不可混用两者的内存数字。CPU/IO 为进程原生计数，内存以 200ms 采样，短峰值可能漏采，I/O 不等于物理磁盘带宽。

报告为独占目录的中文 HTML、机器 JSON、指标 CSV，含机器、版本、构建 Commit（本地未提交构建标为 dirty/unknown）、UTC 时间、范围、原始/恢复哈希与日志路径。不提交机器私人日志和随机二进制文件。
