# Development environment — uv

All Python dependencies and the virtual environment are managed by **uv**. Do not use conda, pip install, poetry or requirements.txt as alternate sources of truth.

## Windows setup (PowerShell)
```powershell
git clone https://github.com/yunfei00/qrft.git
cd qrft
uv python install 3.12
uv sync --all-extras --group dev
uv run pytest -q
uv run ruff check .
uv run ruff format --check .
```

If uv is not installed, see https://docs.astral.sh/uv/getting-started/installation/.

## Dependency and lockfile rules
```powershell
uv add <package>
uv add --optional decoder <package>
uv add --group dev <package>
uv lock
uv sync --locked --all-extras --group dev
```

Commit **uv.lock** to GitHub as soon as dependencies are resolved. CI should then use `uv sync --locked` (not unlocked sync). The lockfile is intentionally not hand-written; it must be generated by uv itself.

The Python interpreter is pinned by `.python-version`; project compatibility is constrained in `pyproject.toml`.

## Current state
This is a **scaffold**, not a working encoder or decoder. Optional dependencies are preliminary and will be adjusted after raw-binary QR interoperability tests. Windows CI must pass before claiming Phase 0 complete.
